# اصلاح نمایش مدل فعال در difflow

این اصلاحیه برای commit `086c56e` تهیه شده است. مدل فعال در پنل واحد و مدل و پارامترهای استفاده‌شده در نتایج نمایش داده می‌شوند. معادلات و فرض‌های فلش با مدل فعال هماهنگ می‌شوند. تغییر مدل از Console نیز نتایج قبلی را نامعتبر می‌کند.

## نصب در PowerShell

۱. رابط difflow را متوقف کنید. اگر سرور در PowerShell باز است، `Ctrl+C` بزنید.

۲. فایل ZIP را استخراج کنید. از ریشهٔ مخزن، با Python محیط مجازی، نصب‌کننده را اجرا کنید:

```powershell
& .\.venv\Scripts\python.exe "PATH_TO_EXTRACTED_PATCH\apply_gui_model_patch.py" --repo .
```

برای بررسی بدون اعمال، آرگومان `--check` را اضافه کنید. نصب‌کننده commit و محتوای تمام فایل‌های هدف را پیش از نوشتن بررسی می‌کند. اگر فایل هدف تغییر دیگری داشته باشد، متوقف می‌شود. نسخهٔ پشتیبان کنار مخزن در پوشهٔ `difflow-gui-model-backups` ساخته می‌شود. تغییر `src/difflow_ree/database.py` و فایل‌های مثال‌های شما جزو فایل‌های هدف نیستند. نصب‌کننده دستور commit، تغییر شاخه یا push اجرا نمی‌کند.

۳. رابط را دوباره اجرا و مرورگر را با `Ctrl+F5` تازه‌سازی کنید:

```powershell
& .\.venv\Scripts\python.exe -m difflow.gui
```

در پنل فلش، بخش `Active equilibrium model` و در نتایج، بخش `Models used for this solve` را ببینید. مشخصات NRTL شامل ترتیب مواد، ماتریس‌ها و قرارداد `tau=a+b/T` است.

## محدودهٔ این مرحله

فقط کلاس‌های اصلی `Flash` و `EOSFlash` برای TP توصیف می‌شوند. مدل از نمونهٔ واقعی واحد خوانده می‌شود؛ بسته‌های سفارشی به‌طور خودکار رائولت نام‌گذاری نمی‌شوند. انتخاب مدل از منو و ذخیرهٔ خودکار NRTL هنوز اضافه نشده‌اند. پس از راه‌اندازی مجدد، NRTL متصل‌شده در Console باید دوباره فعال شود. بازسازی واحد از طریق بعضی ویرایش‌ها نیز ممکن است مدل اختیاری را حذف کند؛ برچسب جدید وضعیت واقعی را نشان می‌دهد.

این اصلاحیه معادلات یا روش محاسباتی فلش را تغییر نمی‌دهد. همگرایی موازنهٔ ماده، تأیید مستقل همگرایی تعادل نیست. کد فعلی NRTL از ۳۰ تکرار ترکیب استفاده می‌کند.

سورس Svelte و فایل‌های آمادهٔ رابط در بسته وجود دارند؛ استفاده از اصلاحیه به نصب Node.js نیاز ندارد. آزمون روی محیط Linux انجام شده؛ اجرای نهایی و بررسی دیداری روی Windows کاربر هنوز لازم است.
