# انتخاب مدل تعادل در GUI

این بسته روی commit `086c56e`، پس از نصب اصلاحیهٔ نمایش مدل و اصلاحیهٔ `fix2` اعمال می‌شود. پوشهٔ مخزن، محل فایل ZIP و پوشهٔ استخراج‌شده است.

## نصب

ابتدا سرور GUI را با Ctrl+C متوقف کنید. در ریشهٔ مخزن در PowerShell:

```powershell
Expand-Archive -LiteralPath .\difflow-gui-model-selector.zip -DestinationPath .\difflow-gui-model-selector -Force
& .\.venv\Scripts\python.exe .\difflow-gui-model-selector\apply_model_selector.py --repo .
& .\.venv\Scripts\python.exe -m difflow.gui
```

سپس مرورگر را با Ctrl+F5 تازه‌سازی کنید. نصب‌کننده همهٔ فایل‌های هدف را پیش از نوشتن کنترل و از نسخهٔ قبلی پشتیبان‌گیری می‌کند. فایل database.py و مثال‌های کاربر جزو فایل‌های هدف نیستند. هیچ commit یا push انجام نمی‌شود. Node.js برای استفاده لازم نیست.

## استفاده

۱. مثال فلش را باز و واحد flash را انتخاب کنید. بالای کارت مدل فعال، بخش Equilibrium model selection را می‌بینید.

۲. از فهرست یکی از گزینه‌های Raoult، NRTL، Peng–Robinson یا SRK را انتخاب کنید. فهرست در این مرحله برای کلاس اصلی Flash با داده‌های IdealThermo فعال است؛ PHFlash، EOSFlash و کلاس‌های سفارشی انتخابگر تازه ندارند.

۳. برای NRTL آب–اتانول، روی Load water/ethanol example parameters بزنید. این اعداد از tests/test_flash_azeotrope.py مخزن‌اند و در این اصلاحیه مستقلاً با دادهٔ تجربی اعتبارسنجی نشده‌اند. ماتریس‌ها با ترتیب مواد پنل مرتب می‌شوند. برای مخلوط‌های دیگر باید پارامترهای معتبر خودتان را وارد کنید. قرارداد tau=a+b/T است؛ b برحسب کلوین است.

۴. برای EOS، ماتریس kij را وارد کنید. مقدار اولیهٔ صفر یک فرض است؛ انتخاب EOS به‌تنهایی مناسب‌بودن آن برای آب–اتانول را تضمین نمی‌کند.

۵. Apply model را بزنید. مدل فعال باید تغییر کند و نتایج قبلی کنار گذاشته شوند. سپس Solve را بزنید. نام مدل و ماتریس‌های استفاده‌شده در Models used for this solve درج می‌شوند.

۶. با File → Save As فایل را به‌صورت JSON ذخیره کنید. انتخاب و مقادیر مدل پس از بازکردن فایل، Undo/Redo، ویرایش سایر پارامترها و خروجی Python حفظ می‌شوند. تغییر ترتیب مواد نیازمند بازسازی مدل و بستهٔ خواص است.

این تغییر انتخاب مدل را فراهم می‌کند و الگوریتم عددی فلش را تغییر نمی‌دهد. نتیجهٔ دقیق پژوهشی همچنان به اعتبار خواص، پارامترها و بررسی همگرایی تعادل وابسته است.
